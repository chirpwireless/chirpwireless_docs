# How do I use an application's dashboards?

An application's **Dashboard** tab is a convenient way to check the views that belong to a household setup. For example, Home Watch might offer a general home view and a separate view of the garden's sensors.

An installed [solution](installing-a-ready-made-solution.md) arrives with its dashboard connected to its sensors. These are your existing dashboards, grouped with the application. Their widgets continue to use the devices and settings you configured.

<figure><img src="../.gitbook/assets/chirp-add-dashboard-dialog.jpg" alt="The Add dashboard dialog with Icon, Name, Folder, Application and Description fields, where the Application field names the current application"><figcaption><p>Pick the application in the Add dashboard dialog.</p></figcaption></figure>

## How do I check my home from an application?

1. Select **Applications**, then open the application from **My applications**.
2. Choose **Dashboard**.
3. Select the dashboard you want. Each dashboard in the application has its own button above the preview, named after the dashboard.
4. Read the widgets or use the controls available to your account.

Use **Content** when you want to find the sensors or automations behind the view.

## How do I change what a dashboard shows?

Select **Go to the dashboard** to open the original dashboard. Make layout or widget changes there and save them. When you return to the application, it uses the updated dashboard rather than a separate copy.

For detailed instructions, see [Building a Dashboard](../dashboards/building-a-dashboard.md).

## What do the empty messages mean?

* **This application has no dashboards yet** means no dashboard is assigned to the application.
* **This dashboard has no widgets yet** means the dashboard exists but nothing has been added to it.
* **Dashboard is unavailable** means Chirp could not load that dashboard; reload the page, then check your access.

## Why is the Dashboard tab empty?

Open **Content** and look under **Dashboards**. If no dashboard is associated, edit the one you want to use and choose this application in its **Application** field. You can also make a new dashboard and assign it during setup. If a dashboard exists but is not available to you, check your access with the organization's owner.

## Why does the application page say Application not found?

The page shows **Application not found** alone in the middle of the screen, with no tabs and no buttons, when Chirp cannot load that application. Likely causes are that the application was deleted, that the link points to an application from another organization, or that the page could not be read. Choose **Applications** in the sidebar and open **My applications** to see what you can open,. Check the organization in the sidebar, because an application belongs to one organization.
