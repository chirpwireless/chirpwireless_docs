# New Device Request

Got a sensor that Chirp does not recognize yet? No problem. You can ask the team to add support for it by filling out a short form at **Settings > New device request** in the sidebar.

## What You Need to Provide

- **Brand** (required) -- the company that makes your sensor.
- **Model** (required) -- the model name or number printed on the sensor or its packaging.
- **Band** (required) -- the LoRaWAN frequency bands your sensor supports. Check every band that applies. The choices are: AS923, AU915, CN779, EU433, EU868, IN865, ISM2400, KR920, RU864, and US915. Not sure which band? Check the sensor's documentation or product listing.
- **Documentation link** (required) -- a URL to the sensor's product page or technical documentation so the team can look up its specifications.
- **Codec link or code** (optional) -- if you happen to have the sensor's payload codec (the code that translates its raw data into readable values), paste it here or drop in a link. This speeds things up, but it is not required.

## Sending Your Request

Click **Send request** when you are done. A confirmation message -- *"Request has been successfully sent"* -- lets you know everything went through. If something does not work, an error notification appears so you can try again.

Click **Cancel** at any time to clear the form and start over. You stay on the same page.
